# Code for the resolution of Homework 4.1
**Author** Samuel Jorquera

In this directory you can can find the code used for the resolution of Homework 4.1. The main archive is [DE-UNIX.R](DE-UNIX.R), and [Rfxs.R](Rfxs.R) is an archive with accesory functions. The rest or the archives consists of data used for the resolution.

This code is fully based on the DEG analysis by Verdugo, 2011. The original code can be found in the [DE_tutorial](DE_tutorial) directory.
